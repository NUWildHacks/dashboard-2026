# Prepare for WildHacks

Use these steps before you arrive so check-in is fast and stress-free.

### 1. Join the WildHacks 2026 Discord Server

The WildHacks Discord has all important information before, during, and after the event. We recommend downloading
Discord on your phone so you receive announcements in real time.

[Join the Discord server](https://discord.gg/DCefDDT6sq) for updates, events, and organizer messages.

### 2. Log In to the WildHacks Dashboard

Make sure you can access the [WildHacks Dashboard](https://dashboard.wildhacks.net) using the same GitHub account you
used to register.

_Having trouble? Reach out in [#ask-organizers](https://discord.com/channels/1486912812323311747/1486912815456321736) on Discord._

### 3. Save Your WildHacker Code

You will need access to your [WildHacker Code](https://dashboard.wildhacks.net/dashboard) to check in prior to opening
ceremony.

### 4. Pack the Essentials

- 2025-2026 student ID
- Laptop and laptop charger
- Phone and phone charger
- Toiletries (toothbrush, toothpaste, shower supplies, deodorant, etc.)
- Medication, dietary-specific food you may need
- Sleeping bag, blankets, and pillows (optional)

<Callout type="warning" emoji="⚠️">
  We will be checking IDs when you check in. See more information about [checking in](/guide/logistics/checking-in).
</Callout>
