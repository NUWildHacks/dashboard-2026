# Prepare for WildHacks

Use these steps before you arrive so check-in is fast and stress-free.

### 1. Join the {EVENT_NAME_YEAR} Discord Server

The WildHacks Discord has all important information before, during, and after the event. We recommend downloading
Discord on your phone so you receive announcements in real time.

[Join the Discord server](/discord-invite) for updates, events, and organizer messages.

### 2. Log In to the WildHacks Dashboard

Make sure you can access the [WildHacks Dashboard](https://dashboard.wildhacks.net) using the same GitHub/Gmail account you
used to register.
